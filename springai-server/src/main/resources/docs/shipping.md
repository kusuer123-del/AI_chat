# 配送与运费

## 发货时效
- 现货商品在付款后 48 小时内发出，节假日顺延。
- 预售商品以商品详情页标注的发货时间为准。
- 每天 15:00 前的订单当天打包，15:00 之后的订单次日打包。

## 运费规则
- 单笔订单实付满 99 元包邮（偏远地区除外）。
- 未满 99 元收取基础运费 8 元。
- 内蒙古、西藏、新疆、青海、宁夏等偏远地区，无论金额统一收取 15 元运费。
- 港澳台及海外暂不配送。

## 配送公司与时效
- 默认发顺丰速运与中通快递，可在订单备注中指定，指定顺丰需补差价 5 元。
- 华东、华北地区一般 1-2 天送达；东北、西南地区 3-4 天；偏远地区 5-7 天。
- 快递单号在发货后 2 小时内同步到订单详情页，也可以直接问客服单号查询物流。

## 签收异常
- 包裹显示已签收但未收到，请先联系快递员核实，24 小时内仍未解决可申请理赔。
- 外包装破损请当场拍照并拒收，客服会重新补发。
