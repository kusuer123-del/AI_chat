# 退换货政策

## 七天无理由退货
- 签收之日起 7 天内支持无理由退货，商品需保持吊牌完整、不影响二次销售。
- 以下商品不支持无理由退货：定制类商品、贴身衣物、已拆封的食品与化妆品、激活后的数码产品。
- 无理由退货的寄回运费由买家承担；若商品存在质量问题，往返运费由商城承担。

## 质量问题换货
- 签收起 15 天内出现质量问题，可申请换货或退款，需提供问题照片或视频。
- 审核通过后 48 小时内寄出新品，旧件由快递员上门取回，运费到付。

## 退款时效
- 退货入库质检通过后 1 个工作日内发起退款。
- 原路退回：微信、支付宝一般 1-3 个工作日到账；银行卡 3-7 个工作日到账。
- 使用优惠券的订单，退款金额为实付金额，优惠券按规则退回账户。

## 申请方式
- 订单详情页点击「申请售后」，选择退货或换货并填写原因，客服会在 24 小时内审核。
- 也可以直接联系在线客服，提供订单号与问题描述，由客服代为发起。
